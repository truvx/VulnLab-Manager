# Security Policy

## Reporting a vulnerability
Please use GitHub's **Report a vulnerability** feature when available, or contact the maintainer privately through the contact information on the GitHub profile. Avoid publishing exploit details for an unpatched issue.

## Scope
Security reports are welcome for the desktop application, import and archive handling, QEMU process management, network configuration helpers, and release pipeline.

## Safe use
Imported virtual-machine images are untrusted. Use isolated networks, avoid bridging vulnerable targets to production networks, and inspect helper scripts before running them with elevated privileges.
